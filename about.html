How lawyers are listed

What a profile represents

  1. IBP membership on file

    Every listed attorney's Integrated Bar of the Philippines number is recorded on their profile alongside their firm and years of practice.

  2. Practice area verification

    Specialties shown on a profile reflect the matters that lawyer actively takes on, not a generic list of every possible service.

  3. Transparent consultation fees

    Rates are shown upfront on every profile so clients know the cost of a first session before booking.

Note for reviewers

This is a sample project

PH Legal Services is a portfolio piece built to demonstrate a full booking workflow — directory search, filtering, a multi-step form, and a confirmation flow — using plain PHP, HTML, CSS, and JavaScript with no database. Lawyer profiles, reviews, and availability are fictional. The booking endpoints (php/get-lawyers.php, php/book.php) read and write flat JSON files and are meant to run under a local PHP server such as Laragon; the deployed static version on Vercel uses the same front end with a client-side data source so the demo works without a live backend.
